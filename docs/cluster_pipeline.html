🧩 代码元素聚类过滤方案

基于聚类算法的代码搜索结果优化方案，通过语义聚类发现代码元素间的隐式关联， 实现更精准的离线过滤，提升搜索精度并降低LLM调用成本。

1 方案概述

项目背景

CodeSearch 是一个智能代码搜索系统，旨在帮助开发者在大型代码库中快速定位目标代码元素。 当前系统已实现了完整的搜索流程：

🏗️ 现有系统架构
  • 倒排索引搜索：基于关键词和子词（sub-token）的高效召回
  • 类型过滤：根据 target 字段过滤代码元素类型（function/class/module）
  • 语义过滤：利用LLM对候选代码进行深度语义分析
  • 重排序：综合多维度得分对结果进行排序

当前问题

虽然现有系统能够有效过滤大部分无关结果，但仍存在以下挑战：

⚠️ 召回率过高问题

  • 倒排索引召回大量候选，单个元素过滤效率低
  • 同义词扩展可能导致语义偏移
  • 类型过滤粒度较粗，难以精确匹配

💰 LLM成本问题

  • 语义过滤依赖LLM逐个分析代码元素
  • 候选集过大时API调用成本高
  • 实时性受限于LLM响应速度

🔍 隐式关联缺失

  • 当前方案逐个评估元素，忽略元素间关系
  • 功能相似的代码未被充分利用
  • 缺乏全局视角的过滤策略

解决方案

聚类过滤方案 通过对搜索结果进行聚类分析，从"组"的角度评估相关性， 实现更高效的过滤策略：

💡 核心思想

相似功能的代码元素倾向于聚集在同一个簇中。 通过评估整个簇与查询的相关性，可以：

  • 批量过滤低相关性的簇，减少待评估元素数量
  • 发现代码元素间的隐式语义关联
  • 降低对LLM的依赖，节省成本
  • 提供更可解释的过滤结果

流程步骤详解

  1. 获取搜索结果代码元素 从倒排索引搜索获取候选代码元素集合，每个元素包含： 名称、类型、文件路径、代码内容等基本信息
  2. 提取代码内容特征 对每个代码元素提取多维特征：语义向量、结构特征、命名特征等
  3. 执行聚类算法生成簇 应用聚类算法（K-Means/DBSCAN等）将相似代码元素分组
  4. 计算簇与Query的相关性 计算每个簇的中心向量与Query Embedding的相似度
  5. 根据相关性排序簇 按相似度得分对簇进行降序排列
  6. 分层过滤策略 高相关性簇直接保留，中相关性簇LLM精筛，低相关性簇批量过滤
  7. 返回过滤后的结果 合并各层过滤结果，输出最终候选集及过滤解释

3 可行性分析

✅ 优点

  • 发现隐式语义关联：聚类可以揭示代码元素间的深层语义关系，超越字面匹配
  • 相似功能聚集：功能相近的代码自然聚集，便于整体评估
  • 全局视角过滤：从簇层面判断相关性，比逐元素评估更高效
  • 降低LLM成本：批量过滤低相关性簇，减少API调用次数
  • 可解释性强：簇的语义标签和相关性得分提供清晰的过滤依据
  • 并行化友好：簇间评估可并行处理，提升效率

⚠️ 挑战

  • 聚类算法选择：K-Means需预设簇数，DBSCAN参数敏感
  • 特征质量依赖：Embedding质量直接影响聚类效果
  • 计算开销：实时场景下聚类可能增加延迟
  • 相关性计算准确性：簇中心可能不能完全代表簇内元素
  • 边界情况处理：小簇和噪声点的过滤策略需特殊处理
  • 参数调优复杂：不同查询场景可能需要不同参数

建议方案

技术环节 推荐方案 替代方案 说明
聚类算法 K-Means（候选数/3~5） DBSCAN、层次聚类 K-Means简单高效，适合中等规模候选集
特征提取 代码Embedding + 命名特征 AST特征、调用图特征 Embedding捕捉语义，命名特征补充结构信息
簇相关性计算 簇中心与Query余弦相似度 簇内所有元素相似度均值 簇中心计算高效，适合快速评估
部署模式 在线过滤补充 离线预处理 作为现有流程的补充，不替代原有过滤
💡
实施建议

建议采用"渐进式集成"策略：初期作为实验性功能，对部分查询应用聚类过滤， 逐步积累数据和经验后再全面推广。同时保留原有过滤流程作为兜底方案。

4 详细算法设计

4.1 特征提取方法

特征提取是聚类质量的关键，我们设计多维度特征融合方案：

🔤 语义特征 (Semantic Features)

  • 代码Embedding向量：使用预训练模型（如CodeBERT）对代码内容编码
  • 维度：768维（可降维至128-256维）
  • 捕获信息：代码语义、功能意图、API使用模式

📋 结构特征 (Structural Features)

  • AST特征：语法树深度、节点类型分布
  • 代码行数：代码规模指标
  • 复杂度指标：圈复杂度、嵌套深度

🏷️ 命名特征 (Naming Features)

  • 标识符Token：函数名、变量名的子词序列
  • 命名模式：camelCase/snake_case检测
  • 关键词匹配：常见动词/名词统计

🔗 上下文特征 (Context Features)

  • 调用关系：调用/被调用函数信息
  • 所属类/模块：包名、类名路径
  • 依赖信息：import语句、依赖库
Feature Vector = [Embedding; Structure; Naming; Context] ∈ ℝd

4.2 聚类算法选择

算法 优点 缺点 适用场景 推荐度
K-Means 简单高效 可扩展性强 结果稳定 需预设K值 对噪声敏感 中等规模候选集，簇分布较均匀 ⭐⭐⭐⭐⭐
DBSCAN 无需预设簇数 可发现任意形状簇 自动识别噪声 参数敏感 高维数据效果差 密度不均匀的数据，噪声较多场景 ⭐⭐⭐⭐
层次聚类 簇层次结构清晰 无需预设参数 计算复杂度高 不适合大规模 小规模候选集，需要层次解释 ⭐⭐⭐
GMM 概率模型 软聚类 假设高斯分布 可能收敛到局部最优 需要概率输出的场景 ⭐⭐⭐
🎯 推荐配置

首选：K-Means

  • K值设定：K = max(2, len(candidates) // 5)，通常3-10簇
  • 初始化：k-means++ 初始化，避免局部最优
  • 距离度量：余弦相似度（适合文本/代码向量）
  • 迭代次数：最大100次，提前收敛则停止

4.3 簇相关性计算方法

计算每个簇与查询的相关性是过滤策略的核心依据：

计算方法

Similarity(C, Q) = cosine(μC, vQ) = μC · vQ/‖μC‖ × ‖vQ‖

其中：

  • μC：簇C的中心向量，即簇内所有元素向量的均值
  • vQ：查询Q的Embedding向量
⚠️ 注意事项
  • 簇中心计算使用加权平均，可考虑元素质量权重
  • 对于小簇（元素数 < 3），建议结合簇内元素与查询的最小相似度
  • 可引入簇紧密度作为置信度调整因子

FILTER_THRESHOLDS = {
    'high_relevance': 0.7,    # 高相关性阈值
    'low_relevance': 0.4,     # 低相关性阈值
    'min_cluster_size': 2,    # 最小簇大小（小簇特殊处理）
    'sample_ratio': 0.1,      # 低相关性簇抽样验证比例
}

def determine_filter_strategy(cluster_score, cluster_size):
    """根据簇得分和大小确定过滤策略"""
    if cluster_size < FILTER_THRESHOLDS['min_cluster_size']:
        return 'SINGLE_ELEMENT_EVAL'  # 小簇单独评估
    
    if cluster_score >= FILTER_THRESHOLDS['high_relevance']:
        return 'KEEP_ALL'              # 直接保留
    
    elif cluster_score >= FILTER_THRESHOLDS['low_relevance']:
        return 'LLM_FILTER'            # LLM精筛
    
    else:
        return 'BATCH_FILTER'          # 批量过滤

5 实现建议

5.1 核心伪代码实现

import numpy as np
from sklearn.cluster import KMeans
from typing import List, Dict, Tuple

class ClusterBasedFilter:
    """基于聚类的代码元素过滤器"""
    
    def __init__(self, 
                 embedding_model,
                 k_ratio: float = 0.2,
                 high_threshold: float = 0.7,
                 low_threshold: float = 0.4):
        self.embedding_model = embedding_model
        self.k_ratio = k_ratio
        self.high_threshold = high_threshold
        self.low_threshold = low_threshold
    
    def extract_features(self, symbols: List[Dict]) -> np.ndarray:
        """提取代码元素特征向量"""
        features = []
        for symbol in symbols:
            # 获取代码内容
            code_content = symbol.get('content', '')
            # 生成Embedding向量
            embedding = self.embedding_model.encode(code_content)
            # 可选：拼接命名特征等
            # feature = np.concatenate([embedding, naming_features])
            features.append(embedding)
        return np.array(features)
    
    def cluster_symbols(self, 
                       features: np.ndarray, 
                       n_clusters: int) -> Tuple[np.ndarray, np.ndarray]:
        """执行K-Means聚类"""
        kmeans = KMeans(
            n_clusters=n_clusters,
            init='k-means++',
            max_iter=100,
            random_state=42
        )
        labels = kmeans.fit_predict(features)
        return labels, kmeans.cluster_centers_
    
    def compute_cluster_relevance(self,
                                  query_embedding: np.ndarray,
                                  cluster_centers: np.ndarray) -> np.ndarray:
        """计算簇与查询的相关性"""
        # 余弦相似度
        similarities = []
        for center in cluster_centers:
            sim = np.dot(query_embedding, center) / (
                np.linalg.norm(query_embedding) * np.linalg.norm(center)
            )
            similarities.append(sim)
        return np.array(similarities)
    
    def filter_by_clusters(self,
                          symbols: List[Dict],
                          query: str,
                          semql: Dict) -> List[Dict]:
        """主过滤函数"""
        # 1. 特征提取
        features = self.extract_features(symbols)
        query_embedding = self.embedding_model.encode(query)
        
        # 2. 确定聚类数
        n_clusters = max(2, len(symbols) // 5)
        
        # 3. 执行聚类
        labels, centers = self.cluster_symbols(features, n_clusters)
        
        # 4. 计算簇相关性
        relevance_scores = self.compute_cluster_relevance(query_embedding, centers)
        
        # 5. 分层过滤
        filtered_symbols = []
        filter_report = {
            'kept_by_high_relevance': [],
            'filtered_by_llm': [],
            'batch_filtered': []
        }
        
        for cluster_id in range(n_clusters):
            cluster_mask = labels == cluster_id
            cluster_symbols = [s for s, m in zip(symbols, cluster_mask) if m]
            score = relevance_scores[cluster_id]
            
            if score >= self.high_threshold:
                # 高相关性：直接保留
                filtered_symbols.extend(cluster_symbols)
                filter_report['kept_by_high_relevance'].append({
                    'cluster_id': cluster_id,
                    'score': score,
                    'count': len(cluster_symbols)
                })
            
            elif score >= self.low_threshold:
                # 中相关性：LLM精筛
                llm_filtered = self.llm_filter(cluster_symbols, semql)
                filtered_symbols.extend(llm_filtered)
                filter_report['filtered_by_llm'].append({
                    'cluster_id': cluster_id,
                    'score': score,
                    'kept': len(llm_filtered),
                    'total': len(cluster_symbols)
                })
            
            else:
                # 低相关性：批量过滤（可选抽样验证）
                filter_report['batch_filtered'].append({
                    'cluster_id': cluster_id,
                    'score': score,
                    'count': len(cluster_symbols)
                })
        
        return filtered_symbols, filter_report
    
    def llm_filter(self, symbols: List[Dict], semql: Dict) -> List[Dict]:

5.2 效果评估方法

📊 离线评估指标

  • 召回率：聚类过滤后保留的正确结果占比
  • 精度：过滤后结果的正确率
  • F1分数：召回率和精度的调和平均
  • 成本节省：LLM调用次数减少比例

⚡ 在线评估指标

  • 延迟影响：聚类步骤增加的时间
  • 用户满意度：A/B测试用户反馈
  • 点击率：搜索结果的点击行为
  • 任务完成率：用户找到目标代码的成功率
# 评估函数示例
def evaluate_clustering_filter(
    test_queries: List[Dict],
    ground_truth: Dict[str, List[str]]
) -> Dict:
    """评估聚类过滤效果"""
    
    total_recall = 0
    total_precision = 0
    total_cost_saved = 0
    
    for query in test_queries:
        # 执行聚类过滤
        filtered, report = cluster_filter.filter_by_clusters(
            query['candidates'],
            query['text'],
            query['semql']
        )
        
        # 计算召回率
        truth_set = set(ground_truth[query['id']])
        filtered_set = {s['id'] for s in filtered}
        
        recall = len(truth_set & filtered_set) / len(truth_set)
        precision = len(truth_set & filtered_set) / len(filtered_set)
        
        # 计算成本节省
        original_llm_calls = len(query['candidates'])
        actual_llm_calls = sum(
            r['total'] for r in report['filtered_by_llm']
        )
        cost_saved = 1 - (actual_llm_calls / original_llm_calls)
        
        total_recall += recall
        total_precision += precision
        total_cost_saved += cost_saved
    
    n = len(test_queries)
    return {
        'avg_recall': total_recall / n,
        'avg_precision': total_precision / n,
        'avg_cost_saved': total_cost_saved / n
    }

from embedding.code_encoder import CodeEncoder
from sklearn.cluster import KMeans
import numpy as np

# 初始化编码器（可复用现有embedding模块）
_encoder = CodeEncoder(model_name=BASE_MODEL)

def filter_symbols_by_clustering(
    search_result_path: str, 
    semQL_path: str,
    high_threshold: float = 0.7,
    low_threshold: float = 0.4
) -> dict:
    """
    基于聚类的代码元素过滤方法。
    返回分层的过滤结果，供后续流程使用。
    """
    search_results = load_res(search_result_path)
    semql_query = load_res(semQL_path)
    
    if len(search_results) < 5:
        # 候选太少，跳过聚类
        return {
            'high_relevance': search_results,
            'mid_relevance': [],
            'low_relevance': [],
            'report': {'skipped': True, 'reason': 'few_candidates'}
        }
    
    # 1. 提取特征
    features = []
    for symbol in search_results:
        code_content = get_symbol_code(PROJECT_PATH, symbol)
        embedding = _encoder.encode(code_content)
        features.append(embedding)
    features = np.array(features)
    
    # 2. 查询向量
    query_text = semql_query.get('raw_query', '')
    query_embedding = _encoder.encode(query_text)
    
    # 3. 聚类
    n_clusters = max(2, len(search_results) // 5)
    kmeans = KMeans(n_clusters=n_clusters, init='k-means++', random_state=42)
    labels = kmeans.fit_predict(features)
    
    # 4. 计算簇相关性
    cluster_scores = compute_relevance(query_embedding, kmeans.cluster_centers_)
    
    # 5. 分层结果
    result = {
        'high_relevance': [],
        'mid_relevance': [],
        'low_relevance': [],
        'report': {
            'n_clusters': n_clusters,
            'cluster_scores': cluster_scores.tolist(),
            'skipped': False
        }
    }
    
    for i, symbol in enumerate(search_results):
        cluster_id = labels[i]
        score = cluster_scores[cluster_id]
        symbol['cluster_id'] = int(cluster_id)
        symbol['cluster_score'] = float(score)
        
        if score >= high_threshold:
            result['high_relevance'].append(symbol)
        elif score >= low_threshold:
            result['mid_relevance'].append(symbol)
        else:
            result['low_relevance'].append(symbol)
    
    # 保存报告
    save_res(f'{OUTPUT_DIR}/youlai-boot-master/clustering_report.json', result['report'])
    
    return result


def compute_relevance(query_vec: np.ndarray, centers: np.ndarray) -> np.ndarray:
    """计算簇中心与查询的余弦相似度"""
    query_norm = query_vec / np.linalg.norm(query_vec)
    centers_norm = centers / np.linalg.norm(centers, axis=1, keepdims=True)
    return np.dot(centers_norm, query_norm)

# main.py 中的调用流程
from search.filters import (
    filter_symbols_by_type,
    filter_symbols_by_clustering,
    filter_symbols_semantically
)

def run_search_pipeline():
    # Step 1: 类型过滤
    type_filtered = filter_symbols_by_type(
        f'{OUTPUT_DIR}/youlai-boot-master/invert_index_search_result.json',
        f'{OUTPUT_DIR}/youlai-boot-master/semQL.json'
    )
    save_res(f'{OUTPUT_DIR}/youlai-boot-master/filtered_by_type.json', type_filtered)
    
    # Step 2: 聚类过滤（新增）
    cluster_result = filter_symbols_by_clustering(
        f'{OUTPUT_DIR}/youlai-boot-master/filtered_by_type.json',
        f'{OUTPUT_DIR}/youlai-boot-master/semQL.json'
    )
    
    # 高相关性结果直接保留
    high_relevance_symbols = cluster_result['high_relevance']
    
    # 中相关性结果进入语义过滤
    mid_relevance_symbols = cluster_result['mid_relevance']
    if mid_relevance_symbols:
        # 临时保存用于语义过滤
        temp_path = f'{OUTPUT_DIR}/youlai-boot-master/mid_relevance_temp.json'
        save_res(temp_path, mid_relevance_symbols)
        
        # 调用语义过滤
        semantically_filtered = filter_symbols_semantically(
            temp_path,
            f'{OUTPUT_DIR}/youlai-boot-master/semQL.json'
        )
    else:
        semantically_filtered = []
    
    # Step 3: 合并最终结果
    final_results = high_relevance_symbols + semantically_filtered
    
    # 按相关度排序
    final_results.sort(key=lambda x: x.get('cluster_score', 0), reverse=True)
    
    save_res(f'{OUTPUT_DIR}/youlai-boot-master/final_filtered.json', final_results)
    
    # 打印统计信息
    print(f"📊 过滤统计:")
    print(f"  - 高相关性（直接保留）: {len(high_relevance_symbols)}")
    print(f"  - 中相关性（语义过滤后）: {len(semantically_filtered)}")
    print(f"  - 低相关性（已过滤）: {len(cluster_result['low_relevance'])}")
    print(f"  - 最终结果: {len(final_results)}")
    
    return final_results
